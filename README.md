# ORBITAL HEALTH — Public Educational Prototype

A responsive, single-page educational demo for astronaut health monitoring concepts.

## Run locally
Open `index.html` in a modern browser. No build step or dependencies are required.

## Publish a public link (GitHub Pages)
1. Sign in to GitHub and create a new **public** repository, e.g. `orbital-health`.
2. Upload `index.html` and this README to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish. The public URL will appear in the Pages settings.

Alternative: drag the folder into a static hosting service such as Netlify Drop, if available to you.

## Important safety and privacy limitations
- Educational prototype only; not a medical device and not clinically validated.
- Do not use for real astronaut care or personal medical decisions.
- Do not enter real personal, medical, identifying or sensitive data.
- The form works only in the current browser session; it does not transmit data or save it to a server.
- All example chart content is illustrative.
- No live sensor integration, medical thresholds, diagnosis, prescription, or treatment decisions.
- Real deployment requires clinical validation, flight-surgeon and agency approval, cybersecurity review, accessibility and human-factors testing, hardware integration, and mission-specific emergency procedures.

## Included capabilities
- Responsive dashboard and navigation
- Demonstration health check-in form
- Session-only summary
- Illustrative trend chart
- Clickable body-system map
- NASA five-hazard educational section
- Preventive guidance and escalation principles
- Links to NASA and Canadian Space Agency resources
